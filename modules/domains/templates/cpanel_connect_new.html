How to Get a cPanel API Token
  1. Log in to your cPanel account
  2. Go to Security → Manage API Tokens
  3. Click Create
  4. Enter a token name (e.g., "GuardBot")
  5. Copy the generated token and paste it above
The token only needs Zone Editor permissions to manage DNS records.
