How to Get a cPanel API Token
  1. Log in to your cPanel account
  2. Go to Security → Manage API Tokens
  3. Click Create
  4. Enter a name (e.g., "GuardBot DNS")
  5. Click Create
  6. Copy the token shown — you won't be able to see it again
  7. Paste the token in the form above
The API token allows us to add DNS records for domain verification and SSL certificates.
Delete cPanel Connection
Destructive Action

This will permanently delete:

  • The cPanel connection
  • All domains added through this connection
  • All redirect links on those domains
  • All analytics data for those links
  • Server files (nginx config, SSL certificates)

This cannot be undone!
