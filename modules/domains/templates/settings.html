How to Get Turnstile Keys
  1. Go to Cloudflare Dashboard → Turnstile
  2. Click "Add site"
  3. Enter your domain name: *.{{if hasPrefix .Domain.Name "*."}}{{trimPrefix .Domain.Name "*."}}{{else}}{{.Domain.Name}}{{end}}
  4. Select widget type: Managed (recommended)
  5. Copy the Site Key and Secret Key
Free: Turnstile is free for unlimited use.
Without keys, the cloudflare template uses proof-of-work instead of the official Turnstile widget.
What is Turnstile?

Cloudflare Turnstile is a CAPTCHA alternative that verifies visitors are human without the frustration of solving puzzles.

When configured, visitors using the "cloudflare" bot protection template will see the official Cloudflare verification widget instead of proof-of-work.
